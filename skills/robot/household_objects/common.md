# Common Household Objects

## Search Strategy
1. Start by looking straight ahead from current position.
2. If the object is not visible, turn 90° and look again. Repeat up to 4 times for a full 360° scan.
3. If still not found, describe what you DO see and ask the user for help.

## Object Descriptions
- **Keys**: Small metallic objects, often on a keyring. Look on tables, counters, shelves.
- **Phone**: Rectangular device, usually dark screen. Check tables, couches, chargers.
- **Remote**: Rectangular, buttons on top. Usually near TV, couch, coffee table.
- **Glasses**: Two lenses connected by a frame. Check tables, nightstands, cases.
- **Wallet**: Folded leather or fabric rectangle. Check tables, coat pockets, shelves.
- **Cup/Mug**: Cylindrical container with handle. Check tables, kitchen counters, desks.
